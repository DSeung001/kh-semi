# 와이어프레임 피드백

## 잘 잡힌 부분
- 모든 화면에서 왼쪽 메뉴, 중앙 콘텐츠, 오른쪽 로그인 영역의 기본 구조가 반복되어 공용 레이아웃으로 만들기 좋습니다.
- Travelgram 사진 그리드, 피드 상세, 태그 피드, 실시간 톡, 미션 등 서비스 핵심 기능이 구분되어 있습니다.
- 인스타그램형 서비스에 필요한 좋아요, 댓글, 공유, 프로필, 태그 요소가 포함되어 있습니다.

## 추가 설계가 필요한 페이지
1. 회원가입 및 회원가입 완료
2. 아이디 찾기 결과와 비밀번호 재설정
3. 게시물 작성·수정·삭제 및 삭제 확인
4. 알림 목록
5. 다른 사용자의 프로필과 팔로워·팔로잉 목록
6. 검색 결과 통합 화면
7. 신고하기와 차단 관리
8. 미션 인증 심사 결과 및 완료 보상
9. 채팅방 목록과 1:1 채팅
10. 오류, 빈 목록, 로딩 상태

## 기능 설계에서 정해야 할 항목
- 피드의 `content 30자`와 `content 30줄` 중 실제 제한 기준
- Travelgram 사진 그리드의 정렬 기준과 대표 사진 선정 방식
- 미션의 시작일, 종료일, 인원 제한, 성공 조건, 보상 포인트
- 로그인하지 않은 사용자가 볼 수 있는 범위
- 댓글의 대댓글, 수정, 삭제, 신고 여부
- 이미지 여러 장 업로드와 이미지 순서 변경 여부
- 실시간 톡의 공개 채팅인지 지역별 채팅인지
- 이용약관·개인정보처리방침의 실제 문서 페이지

## 반응형 제안
- PC: 왼쪽 고정 메뉴 + 중앙 콘텐츠 + 오른쪽 로그인/추천 영역
- 태블릿: 아이콘형 왼쪽 메뉴 + 중앙 콘텐츠
- 모바일: 상단 로고 + 하단 탭 메뉴
